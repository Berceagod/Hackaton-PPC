# ADR-0018: Grafana behind the gateway, dashboards and datasources as code
Status: accepted (slice H)

## Context
The dashboards are what a person looks at during the demo and during an incident. They must exist on a clean machine with no clicking (PDF §3: one command), and only nginx may publish a port.

## Decision
- **Access.** Grafana is reached at `https://localhost/grafana/` through nginx (TLS, same gateway). It has its own login: user `admin`, password `GRAFANA_ADMIN_PASSWORD`, generated by `start.sh`/`start.ps1` into `.env` (never in git). Sign-up and anonymous access are off, the session cookie is `Secure`, usage reporting and update checks are off. Prometheus, Loki and Alertmanager publish nothing; Grafana reaches them over the internal network, and scripts reach them through Grafana's datasource proxy.
- **Provisioned as code.** `infrastructure/grafana/provisioning/` declares the three datasources (fixed uids `prometheus`, `loki`, `alertmanager`) and a file provider that loads `dashboards/*.json`; `allowUiUpdates: false`, so what is in git is what is shown. The JSON is generated by `build_dashboards.py` (committed next to its output) so the 47 panels stay consistent and reviewable.
- **Three dashboards.**
  - *Operations*: backend instances up, request rate, failure rate, alerts firing, outbox, open breakers; then **per category** ingest and download latency p50/p95/p99, files/s, bytes/s, error rate, outcomes; **per storage** write and read latency p50/p95/p99 (time inside the adapter only), bytes/s, calls/s, error rate, and ingest p95 per category x storage; **isolation** (ingest rate by category next to the others' latency, bulkhead refusals, breakers, integrity failures); the simulator's own metrics.
  - *Business guarantees*: one block per promise of table 2.1 with the signal that shows it is at risk, a red line at the alert threshold on the two latency panels, and the table of alerts firing.
  - *Trace one operation*: a trace-id box and the log views of ADR-0015.
- Time series that list failures hide all-zero lines (`> 0`) because the underlying series start at 0 (ADR-0014).

## Consequences
- Changing a dashboard means editing `build_dashboards.py`, regenerating, and committing the JSON (Grafana re-reads the folder every 30 s).
- The Grafana password lives in `.env`; losing `.env` means a new password and an empty Grafana volume that re-provisions itself.
