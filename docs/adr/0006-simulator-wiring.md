# ADR-0006: Simulator wiring
Status: accepted (updated in slice C)
Decision: The simulator runs as the `simulator` compose service on the internal network, unchanged. Compose passes `API_URL=https://nginx/api/v1/ingest`, `API_TOKEN=${SIMULATOR_TOKEN}` (random secret generated by start.sh; the backend maps it to role `service`) and `VERIFY_TLS=/certs/tls.crt`.
TLS is verified, not disabled: the gateway copies only its public certificate to the `gateway-ca` volume, mounted read-only in the simulator. The private key never leaves the nginx container.
Volume is configurable without code: `SIM_BASE_RATE`, `SIM_STORM_MULTIPLIER`, `SIM_METER_COUNT`, `SIM_DUPLICATE_RATIO`, `SIM_ANOMALY_RATIO`, `SIM_START_MODE` in `.env`, and at runtime through the simulator's control API.
The control API publishes no host port (only nginx does); `scripts/sim.sh` reaches it with `docker compose exec`.
Consequences: no edits to teammates' simulator code.
